AI 与大模型

X 热门只有 11 月 14、15 日两天读到，其余来自 Hugging Face 每日论文和新闻
  1. Gemini 4 Carbon 登顶 MathArena

    帖子称数学评测榜 MathArena 很久以来第一次由非 OpenAI 模型排第一：Gemini 4 Carbon 超过 GPT-6.1 Sol，Fable 5.2 排第二。

  2. X 开源推荐算法：复制链接的权重从 20 改成 0

    帖子称 X 在 11 月 13 日的更新里把原本全系统最高的“复制链接”权重直接清零，并新增针对骗复制链接的垃圾检测；点赞 0.708、回复 5、私信分享 5 没变。这是作者自己读代码的解读，X 官方没解释原因。

  3. 多模态模型该怎么编码视觉输入：200 多个模型的对比

    一位研究者称已发表的模型把“预训练编码器 / 不用编码器 / 在 LLM 之前处理”等选择捆在一起，于是从零训练了 200 多个模型逐项对比，结论是只有其中一项真正有影响，具体哪项在帖子串后面。

  4. 前沿大模型进入机器人：帖子和论文同时出现

    帖子称 Anthropic 报告 Fable 5.2 在机器人能力上出现突然的跃升。同一周的论文里，一篇综述认为“前沿大模型 + agent 框架”几周内就在许多任务上追平专门训练的策略；ForceHarness 则给只能通过 API 调用的冻结多模态模型加上力觉。

  5. OpenAI：72 天没发前沿模型，GPT-6.2 Astra 的传闻

    帖子称 OpenAI 已 72 天没有发布前沿模型，是 GPT-5 到 5.1 之后最长的间隔。另有帖子称一段演示的全部素材由 GPT-6.2 Astra 生成，并猜测会卡在 Anthropic IPO 前后发布，这些都是个人说法，没有官方确认。

  6. “四家中国模型蒸馏自 Anthropic”的指控（未经验证）

    帖子称作者分析公开权重后发现 DeepSeek、Moonshot、MiniMax、蚂蚁的最新模型里残留“指纹”，都是蒸馏 Anthropic 模型得到的。这是个人说法，没有同行验证，方法是否成立存疑。

  7. Agent 降成本的三篇论文：少读、记忆、量化

    SparseRead 让智能体只读网页和文档里需要的片段来省 token；MIRIX-2.0 是多 agent 的长期记忆系统，思路和推荐里的用户长期兴趣建模相通；SteerDistill 用全精度“老师”在闭环里纠偏，让低比特量化后的智能体保住任务成功率。

  8. 韩国税务师考试第一名承认用 AI 作弊

    34 岁的考生承认用隐藏摄像头加 AI，在这场重要考试里拿到接近满分。这是 AI 被用于大型资格考试作弊的一个典型案例。

GitHub 本周

本周趋势榜前 10，几乎全是给编程智能体用的技能和工具
  1. backnotprop/plannotator

    给 AI 编程代理用的本地浏览器审阅界面：批注代理写的计划、审 diff 和 PR，再一键把反馈发回代理；新出的 Inbox 集中处理多个代理的待决事项。

  2. google-labs-code/stitch-skills

    谷歌实验室为设计工具 Stitch 做的一组 Agent 技能和插件，配合 Stitch 的 MCP 服务使用，遵循 Agent Skills 开放标准，Codex、Gemini CLI、Claude Code、Cursor 等都能装。

  3. GoogleChrome/modern-web-guidance-src

    把最新的 Web 平台最佳实践和浏览器兼容性数据做成技能喂给编程代理，避免它按训练数据里的旧写法生成代码；这个仓库是它的源码和评测部分。

  4. alibaba/open-code-review

    阿里开源的 AI 代码评审命令行工具，源自内部用了两年的评审助手：读取 Git diff，用“确定性流水线 + LLM 代理”给出精确到行的意见，内置空指针、线程安全、XSS、SQL 注入等规则。

  5. mvanhorn/last30days-skill

    一个 AI agent 技能：自动在 Reddit、X、YouTube、Hacker News、Polymarket 和网页上调研某个话题最近 30 天的讨论，再写成有出处的总结。

  6. ChromeDevTools/chrome-devtools-mcp

    Chrome 官方的 MCP 服务器和命令行工具，让编程代理能控制并检查一个真实的 Chrome：录性能 trace、看网络请求和控制台报错、截图、自动操作页面。

  7. tradermonty/claude-trading-skills

    面向个人投资者的 Claude Code 技能包，覆盖行情复盘、技术图表、经济日历、选股和交易计划。作者强调是把复盘和风控流程化，不是让 AI 替你做买卖决定。

  8. ag-ui-protocol/ag-ui

    AG-UI 协议：规定 AI 代理怎样和前端应用交互，代理后端在执行过程中发出约 16 种标准事件，前端据此实时更新界面，传输方式不限。

  9. meta/astryx

    Meta 开源的设计系统，内部用了约 8 年，基于 React 19+ 和 StyleX，可高度定制，并专门为“人和智能体一起写界面”设计，目前是 Beta。

  10. pookjw/HermesEnabler

    让任意 Apple Watch 用上爱马仕专属表盘的工具，通过侧载 IPA 安装，只支持 watchOS 27.0 到 27.3 beta 1。

面试题自测

只出题不给答案，先自己讲一遍再去查
  1. Agent 是怎么实现的？MCP 和 Skill 有什么区别？

    出处：牛客热搜“蚂蚁”下的智能体岗一面面经。试着在 3 分钟内讲清一个 Agent 的执行循环，再说 MCP 和 Skill 各自解决什么问题、什么时候用哪个。

  2. 提示词注入怎么防？上下文太长时怎么压缩？

    出处：同一热搜下蚂蚁 AI 应用研发的一面面经。各准备一个你项目里真实遇到或可能遇到的例子，并说明怎么评估做法有没有用。

  3. Agentic RAG 怎么做？PPO 和 DPO 的区别是什么？

    出处：牛客热搜“华为”下的 10 月底北京线下面经，帖子称几乎不问八股、重点拷打实习和项目。两问分开答，PPO 和 DPO 要说清各自的训练信号和适用场景。

  4. 什么是 agent？它和直接调用 API 有什么区别？

    出处：热帖「面试官视角分析，为什么莫名其妙就挂了」，作者说这是他用来帮候选人建立信心的基础题。练习目标是一分钟内有结构地答完。

  5. 排序里某个行为信号被刷了，你会怎么处理？

    出处：X 帖子称 X 把“复制链接”的权重从 20 改成 0 并新增垃圾检测。自测：多目标排序里各行为的权重通常怎么定？一个高权重信号被作弊利用时，除了清零还有哪些做法，各有什么代价？
