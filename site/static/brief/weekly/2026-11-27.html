本周值得投的机会

  • 百度｜生成式排序模型算法工程师（实习）

    大模型 × 推荐方向，北京/上海。做推荐广告场景的生成式排序，探索 Transformer 和序列建模在 CTR/CVR/GMV 预估中的应用，参与多模态大模型在推荐场景的落地实验。要求本科及以上在校生，熟悉 Transformer、DeepFM、DIN 等搜推模型，会 PyTorch 或 TensorFlow。

  • 百度｜推荐算法工程师实习

    搜广推方向，北京，11 月 23 日发布。做 Feed 推荐核心模块：以扶持优质作者为目标的推荐优化、作者冷启动和流量分配机制。要求机器学习和数据挖掘基础，熟悉常用推荐算法，会 Python 或 C++ 和 TensorFlow / PyTorch / PaddlePaddle。官网没写学历要求，投之前在详情页确认。

  • 商汤｜大模型 Agentic 后训练算法实习生

    大模型与 Agent 方向，深圳，11 月 26 日新出现。做领域模型的后训练：构建 Agentic 数据和数据流水线、探索后训练的奖励设计、复现前沿工作。要求相关专业在读本科或硕士，熟悉大模型原理和 SFT、RL 等后训练方法；竞赛获奖、有大模型数据构建经验加分。偏算法研究，不是应用开发岗。

  • B 站｜长视频生成 Agent 算法实习生

    大模型与 Agent 方向，上海，官网没写学历要求。搭“剧本→分镜→生成→VLM 自检→重试→剪辑”的长视频 Agent，负责 planner、工具调用、记忆和跨镜头一致性。要求熟悉 LLM/VLM agent、tool calling、workflow 编排，工程能力强。

  • B 站｜视频理解 PE 数据算法实习生

    多模态方向，上海，官网没写学历要求。分析真实用户 prompt 分布，构造 prompt 改写训练对，产出偏好和 RL 数据，维护评测集。要求熟悉 LLM SFT 和偏好数据构建、会 Python。

  • B 站｜视频理解 RL 算法实习生

    多模态方向，上海，官网没写学历要求。在 verl 等框架上给视频理解模型做强化学习，设计奖励、优化长视频 rollout、分析 reward hacking。要求熟悉 GRPO/PPO/DAPO 中至少两种和一种训练框架，有 VLM 后训练经验，门槛偏高。

世界

来自 BBC World，同一事件多天出现的已合并
  1. Anthropic 上市，一周后美股因 AI 担忧下跌

    Anthropic 在股市挂牌，首日就成为全球市值最高的上市公司之一，是第一家上市的纯 AI 公司，被当作 AI 行业估值的试金石。到 11 月 26 日，BBC 报道美股三大指数继续走低，纳斯达克早盘跌近 4%，报道称原因是市场对 AI 的担忧加剧。

  2. 美国对中国、欧盟等多国加征新关税

    美国宣布对一批国家加征新关税，对象包括中国、欧盟等最大的几个贸易伙伴。这会直接影响全球贸易和出口企业，后续要看各方是否反制。

  3. COP31 气候大会破裂，没有达成重要协议

    近 200 个国家围绕是否在文件里提到化石燃料争执不下，谈判先陷入僵局，在原定结束日期两天后破裂，是该峰会历史上持续最久的一次。BBC 分析称产油国利益、美国的抵制和气候资金分歧是主要原因。

  4. 英伟达风波：加州调查、Megaspeed 将被列黑名单、黄仁勋复职后股价跌 7%

    上周黄仁勋离任后，本周加州就对华 AI 芯片问题调查英伟达；报道称美国准备把被指向中国转运芯片的亚洲 AI 公司 Megaspeed 列入黑名单。随后黄仁勋重新执掌英伟达，议员要求说明特朗普在其中的角色，司法部长回避提问，英伟达股价下跌 7%。

  5. 中美俄首次三方会晤并发表“和平宣言”，欧洲称准备好与俄谈判

    特朗普、普京和习近平举行首次三方会谈后发表“和平宣言”。同一时间乌克兰的欧洲盟友在柏林峰会上表示已形成统一的谈判立场，准备就结束乌克兰战争与俄罗斯会谈。

  6. 俄乌战事外溢：芬兰湾和利比亚的俄方船只相继遇袭

    一艘驶往俄罗斯的船在芬兰湾遭无人机袭击，芬兰国防军说很可能是乌克兰所为；随后泽连斯基称乌克兰无人机在利比亚港口击中一艘俄罗斯军舰，BBC 分析认为战争的打击范围已延伸到北非。另有报道称泄露的俄方数据显示俄军已损失近 50 万人。

  7. 美国中期选举：民主党拿下 1992 年以来最大的众议院多数

    民主党翻转北卡罗来纳州一个席位后，在众议院至少拿到 258 席，共和党至少 173 席，会明显制约总统后两年的施政。

  8. 两起判决和一次辞职：缅甸、华为、韩国教育部长

    国际法院裁定缅甸对罗兴亚人犯下种族灭绝罪；纽约陪审团裁定华为窃取商业秘密罪名成立、敲诈勒索罪名不成立。韩国教育部长崔教振辞职，他承认高考前临时推出的防 AI 辅助作弊措施造成了混乱。

AI 与大模型

X 本周只有 11 月 20 日和 26 日读到；论文来自 Hugging Face 每日论文
  1. OpenAI 公布历代前沿模型的预训练损失

    评测机构 METR 称，OpenAI 公布了从 GPT-3.5 起所有前沿模型的预训练损失，2026 年初以来对数困惑度的下降速度约是 2022–2025 年的 7 倍。METR 认为公开这类数据有助于公众理解 AI 研发在加速。

  2. 通用语言模型开始做蛋白质设计

    《自然》报道，Anthropic 和 OpenAI 的通用语言模型已经能设计蛋白质并预测序列和结构，这些能力以前只有专门的生物 AI 工具才有。Greg Brockman 也发帖称 GPT-6 设计新蛋白质不需要生物专用模型。

  3. 几家模型公司的排位在松动（多为博主解读）

    帖子称 Anthropic 自 9 月以来第一次丢掉某编程能力榜第一，被一款便宜 62% 的 Google 模型超过；另有博主认为这是几年来第一次可以认真地说 OpenAI 排在第三。都是个人判断，没有官方数据。

  4. 用真实用量代替模型评测

    开发者 thdxr 说大家总是怀疑模型评测，于是直接晒出自己团队上周各模型的实际用量图表，是 20 日点赞最高的一条。做 Agent 选型时，“实际用了多少”比榜单更有说服力。

  5. ChatGPT 广告在推进

    Greg Brockman 发帖称 ChatGPT 广告让小品牌也有机会和大品牌竞争，说明对话产品里的广告业务已经在做，和搜广推方向有关。帖子没有给出数据。

  6. 论文：Agent 会“偷懒”，证据不够就提前作答

    论文指出做长任务的 Agent 常在自己陈述的信念里还有多个候选答案时就下结论，只在结尾按结果给奖励管不住；作者用“可验证的信念”做强化学习来纠正。面试聊 Agent 评估和奖励设计时可以用。

  7. 论文：Agent 自我进化的关键是识别出真改进

    研究 Agent 的自我进化循环（提出新的提示词、技能、记忆，再按得分筛选）为什么有时不起作用，提出“分辨率假说”：关键不在怎么提方案，而在能不能准确识别哪些改动是真的改进。

  8. 论文：开源全模态视频理解模型 WeMM-Video

    一组中英双语的开源全模态视频理解基础模型，有 2B、4B、9B 和 35B-A3B 几个规模，重点做带音频的音视频联合感知。和 B 站本周新开的视频理解实习方向一致。

GitHub 本周

本周趋势前 10，几乎全是给编程 Agent 用的技能、协议和工具
  1. backnotprop/plannotator

    盯住编程 Agent 的工作台：定方向、做决定、写计划、批注、审代码、和团队分享，再一键把所有反馈发回给 Agent。

  2. google-labs-code/stitch-skills

    配合 Stitch MCP 服务器使用的一组 Agent 技能，遵循 Agent Skills 开放标准，可用于 Antigravity、Gemini CLI、Claude Code、Cursor 等编程 Agent。

  3. GoogleChrome/modern-web-guidance-src

    Chrome 团队维护的指引，让编程 Agent 写网页代码时跟上最新的 Web 最佳实践。

  4. n8n-io/nod

    n8n 出的开源个人 Agent，有自己的一台“电脑”：在真实网站上催发票、准备通话、取消试用，动手前会先问你；在本机运行，模型自选。

  5. alibaba/open-code-review

    阿里开源的代码评审工具，确定性流水线加 LLM Agent 的混合架构，给出行级评论，内置多语言规则集（空指针、线程安全、XSS、SQL 注入），兼容 OpenAI 和 Anthropic 接口。“规则 + Agent”的混合设计值得看。

  6. mvanhorn/last30days-skill

    一个 Agent 技能：就某个话题去查 Reddit、X、YouTube、Hacker News、Polymarket 和网页上最近 30 天的内容，按点赞和预测市场下注排序，再汇总成有出处的总结。

  7. ChromeDevTools/chrome-devtools-mcp

    给编程 Agent 用的 Chrome 开发者工具 MCP 服务器，让 Agent 能直接调试和检查浏览器里的页面。

  8. tradermonty/claude-trading-skills

    面向股票投资者和交易者的 Claude Code 技能：市场分析、技术图表、经济日历、选股器和交易策略开发。

  9. ag-ui-protocol/ag-ui

    AG-UI，Agent 与用户交互的协议，用来把 Agent 接进前端应用。做 Agent 应用开发可以了解它和 MCP 各管哪一段。

  10. meta/astryx

    Meta 开源的设计系统，可完全定制，并且为 Agent 使用做了准备。

面试题自测

只出题，不给答案；先自己讲一遍再去查
  1. Agentic RAG 怎么做？

    和普通 RAG 相比多了哪些环节，什么时候值得用、什么时候不值得？出处：牛客热搜“华为”下的 10 月底北京线下面经，帖子称几乎不问八股，重点拷打实习和项目。

  2. PPO 和 DPO 的区别是什么？

    各自优化的目标、需要的数据和适用场景分别是什么？出处：同一篇华为线下面经。可以顺带对照 B 站实习 JD 里提到的 GRPO、DAPO 和 reward hacking。

  3. MCP 和 Skill 是什么关系？为什么要把 MCP 目录传给 Agent？

    出处：牛客热搜“蚂蚁”下的智能体岗一面面经，面试官先问 Agent 怎么实现，再追问这两点。

  4. 提示词注入怎么防？上下文太长怎么压缩？

    各说出至少两种做法，并说明各自的代价。出处：牛客热搜“蚂蚁”下的 AI 应用研发一面面经。

  5. Agent 应该跑在浏览器还是后端？

    从安全、密钥、延迟、状态保存几个角度讲你的选择和理由。出处：牛客热搜“拼多多”下 11 月上旬的服务器开发一面面经。
