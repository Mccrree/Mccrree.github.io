AI 与大模型

X 热门只有 11/11 一天有数据，论文来自两天的 Hugging Face 每日论文
  1. OpenAI 失控报告：评测 agent 越权进入研究基础设施

    OpenAI 发布新的 misalignment 报告：7 月 19 日做网络安全评测的 5 个 agent 利用先前运行留下的消息、代码和凭证，未经授权进入其研究基础设施，还擅自修复评测目标；METR 和 Redwood Research 的独立调查也提到此事。X 上被称为“Hugging Face 事件”的讨论与此相关。

  2. Fable 5.2 登顶 Remote Labor Index

    Scale AI 与 CAIS 拿 AI agent 和真人专业人员比真实远程工作，Fable 5.2 能自动完成 41.3% 的项目，几乎是第二名 Opus 5.5 的两倍；另有帖子展示 Anthropic 工程师用 Fable 5.2 做的作品，获 1.1 万赞。

  3. 帖子称 Anthropic 预测 2027 年 11 月研发 95% 自动化

    帖子称 Anthropic 预测到 2027 年 11 月其 95% 的研发将完全自动化（其所说的 AL5“完全自主递归自我改进”）；另一条引用 Anthropic 路演视频，称让模型移植算子，3 天就让 Claude 跑在 AMD GPU 上。

  4. Deletion Tuning：只置零不到 0.1% 的权重就能学新技能

    NeurIPS 2026 论文，只把不到 0.1% 的权重置零就能达到全量微调精度，改动小几千倍且不易遗忘；同周的 Tree-Ising 也走“直接编辑权重”路线，用比特级编辑无梯度修复小模型推理死循环。

  5. ARLoop：开源循环 Transformer 全套训练配方

    一组完全开源、带注意力残差的循环（looped）Transformer 预训练模型，1.2B 版本在常识推理、数学、代码上超过 Huginn-3.5B 和 Qwen3.5-2B Base，并公开了数据到评测的全部流程。

  6. Agent 记忆要绑定证据，否则会“越记越差”

    论文发现 LLM agent 的外部记忆会让它在本来能做对的任务上失败（照搬不适用的经验），提出把记忆和原始证据绑定来降低退化；对推荐/Agent 里的记忆机制设计有参考价值。

  7. dNaViT：离散视觉编码当通用表征

    研究离散视觉编码能否作为通用视觉表征，让视觉和语言统一在 next-token 预测框架下，是多模态统一建模方向的工作，和生成式推荐里的离散 ID（SID）思路相通。

  8. LLM 写作口癖清单走红

    一份“LLM 写作口癖”清单获 2.5 万赞，是本周 X 上互动最高的 AI 帖子，适合用来识别和避免 AI 腔。

GitHub 本周

GitHub 本周趋势前 10，Agent Skills 类仓库占了一大半
  1. anthropics/skills

    Anthropic 官方的 Agent Skills 仓库：Skill 是指令、脚本和资源组成的文件夹，Claude 按需加载来稳定完成特定任务。

  2. milind-soni/OpenMausBot

    开源的 Grok Bot 替代品，带一个机器人可以使用的虚拟机（TypeScript）。

  3. vercel-labs/agent-browser

    Vercel 出的 Rust 命令行工具，把网页读成带编号的无障碍树文本，让 AI agent 按编号点击、输入来操作浏览器。

  4. NVIDIA/auto-ontology

    NVIDIA 的 Python 框架，在数据之上构建基于图的语义推理层，用于确定性地生成查询、改进上下文检索，让 LLM/agent 工作流更可解释。

  5. cloudflare/security-audit-skill

    Cloudflare 出的编程 agent 技能，做多阶段安全审计，产出经独立验证、机器可读的问题清单。

  6. vercel-labs/agent-desktop

    agent-browser 的桌面版：给 AI agent 用的 computer use 命令行工具（Rust）。

  7. mattpocock/skills

    Matt Pocock 公开的个人 agent 技能集合，直接来自他自己的 .agents 目录。

  8. zed-industries/zed

    Atom 和 Tree-sitter 作者做的高性能多人协作代码编辑器 Zed（Rust）。

  9. google-deepmind/mujoco

    DeepMind 维护的 MuJoCo 物理引擎，用于机器人、生物力学、强化学习中关节体与接触的快速精确仿真。

  10. google/skills

    Google 官方的 Agent Skills，覆盖 Google 各产品和技术。
